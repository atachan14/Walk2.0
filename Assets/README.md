# Walk2

Walk2は、ランダム生成マップを繰り返しプレイすることを想定した、軽量な探索ゲームです。
ランキング機能とオートセーブ機能を実装しています。

PlayStoreでの公開を予定して制作していましたが、
審査基準となるテスト体制を整えることが難しかったため、
今回はitch.io上での公開としました。

---

## デモ / 配布ページ

- itch.io:https://atachan14.itch.io/walk2

Android端末向けにビルドしています。

---

## 使用技術

- Unity（Unity 6系）
- Firebase
  - オンラインランキングの保存・取得
  - 進行状況のセーブ・ロード
- 対象プラットフォーム
  - Android
  - PC（Unity Editor上で動作確認）

---

## 設計・工夫点

- **完成を最優先**
  - 1か月程度で最後まで作り切ることを目標に設計しました。

- **ランキング機能の実装**
  - Firebaseを用い、ランキングが成立する構成にしています。
  - 不要な個人情報は保持しない設計です。

- **要件の割り切り**
  - チュートリアルを行わなくとも操作やゲーム性を理解できる形を目指しました。
  - 最初期は「川」と「橋」というギミックが存在していましたが、
    テストしてみるとプレイ体験を損ねるギミックだったため要件から外しました。

---

## 課題・今後の改善点

- 初見プレイヤーがゲーム性を即座に理解できるかは検証が不十分
- ゲーム性が想定以上に単調で、作業的
    - スマートフォンの画面幅を考慮し、可視化タイルは前方のみとしましたが、
      左右と前方斜めのタイルも可視化したほうが
      プレイに工夫の余地が生まれたかもしれない
- UI演出やフィードバックの強化

PlayStoreでの公開が難しいことが判明したため、
実装コストと完成度のバランスを取り、これらは未対応としました。
